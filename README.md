# Signal Sprint

A fast-paced neon reflex game. Click the targets, build your streak, and beat your high score.

## How to play

- Click or tap the glowing target as quickly as possible.
- Keep your streak alive to earn bonus points.
- Watch the timer and avoid missing targets.
- Use the sound button to toggle audio feedback.

## Run locally

Open `index.html` directly in a browser, or start a local server:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publish with GitHub Pages

1. Upload `index.html`, `style.css`, `script.js`, and this README to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose your main branch and the repository root, then save.

GitHub will publish the game at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Tech

Built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.
